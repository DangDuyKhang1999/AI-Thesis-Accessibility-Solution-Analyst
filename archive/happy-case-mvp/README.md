# Happy Case MVP Archive

This completed MVP is preserved as a runnable archive. Create a project-root
`.env` file with `GEMINI_API_KEY`; `HF_TOKEN` is optional.

Run the web app directly:

```powershell
streamlit run archive/happy-case-mvp/streamlit_app.py
```

Or use the archive launcher:

```powershell
python archive/happy-case-mvp/run_happy_case.py
```

Default sample images are stored in `archive/happy-case-mvp/assets/samples/`.
